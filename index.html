60-second walkthrough

Follow this path to show the full attention loop. The interface will cue the next step as you go.

  1. 1
    Launch the task

    Type your request in the message box, then send it.

  2. 2
    Answer while it thinks

    Select both “Fat loss” and “Muscle support”, then choose “3 meals + 1 snack” and “Yes”.

  3. 3
    Add one personal cue

    Select “Asian-inspired” and “Mediterranean”, then write “prep lunches on Sunday”.

  4. 4
    Continue the loop

    Choose Fill as Context, send the next prompt, then answer the new shopping and prep questions.

Design logic

Q2Focus starts immediately after submission, stays non-blocking, and withdraws when the answer arrives.
